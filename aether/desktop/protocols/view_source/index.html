Module view_source 

Source
Expand description

Serves view-source:<url> by fetching <url> and returning its bytes as a numbered, syntax-coloured listing, in the manner of Firefox’s source view.

Modules§

document 🔒
Builds the numbered listing shown for a view-source: URL.
markup 🔒
A markup scanner detailed enough to colour a source listing. It is deliberately not a conforming HTML tokenizer: it never rewrites or drops anything, so that the runs it returns can be reassembled into the original source.
