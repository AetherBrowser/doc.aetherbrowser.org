aether::desktop::protocols::view_source

Module markup 

Source
Expand description

A markup scanner detailed enough to colour a source listing. It is deliberately not a conforming HTML tokenizer: it never rewrites or drops anything, so that the runs it returns can be reassembled into the original source.
