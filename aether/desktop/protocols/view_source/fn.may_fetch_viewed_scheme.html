Whether the inner URL may be fetched.

http and https are reachable from a page already. file: reads the local disk, and data: is not a local file but is still not a web navigation. The address bar and the View Source menu set Request::embedder_initiated. A reload of that page sets reload_navigation and keeps the same URL. A file: document may view another file: URL, which matches the file handler.
