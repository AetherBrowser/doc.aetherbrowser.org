Module search 

Source
Expand description

Search engines configured for the shell.

Firefox stores this choice in the profile as search.json.mozlz4: the configured engines, plus defaultEngineId (user choice) falling back to appDefaultEngineId. Built-in engines are recorded by id. An engine the user added also stores its URL template ({searchTerms}).

Aether keeps the same split in plain JSON at {config_dir}/search.json. {searchTerms} is accepted and stored as %s, which the location bar already substitutes. Changes from about:settings#search are written back to that file.
