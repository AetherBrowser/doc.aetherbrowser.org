Module content_filter 

Source
Expand description

Blocks HTTP requests that match a list of sites and URLs.

The profile directory holds two files:

  • blocklist.txt — one site, URL, or network filter per line
  • content_filter.json for tracking protection settings:
    • privacy.trackingprotection.enabled
    • urlclassifier.trackingWhitelistTable — hosts that are never blocked
    • urlclassifier.trackingTable — extra filter files, beside blocklist.txt

servo:settings#network writes those files. The resource thread reads them when a request is about to be sent, and again when either file changes.

Accepted lines are hosts (example.com), URLs (example.com/ads), and the network rules used by the earlier adblock prototype (||tracker.com^, @@||tracker.com/ok^, $script, $third-party, $domain=). Cosmetic rules (##) are skipped: this filter only refuses network requests.
