Crate aether_places 

Source
Expand description

The places database of an Aether profile, stored in SQLite.

The database follows the model of Firefox’s places.sqlite: places lists each URL once, visits has one row per visit, dated in microseconds since the Unix epoch (UTC), and bookmarks has one row per bookmarked place. To read the visits by hand:

sqlite3 places.sqlite "SELECT datetime(visit_date / 1000000, 'unixepoch', 'localtime'), url
    FROM visits JOIN places ON places.id = visits.place_id ORDER BY visit_date"
